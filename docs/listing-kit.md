## Short blurb (~50 words)

> GitBench is a free, open-source desktop Git client built for working across
> many repositories at once. Group every repo in one sidebar and switch
> instantly, explore a visual commit graph, stage changes with inline diffs, and
> manage branches, worktrees, stashes, and submodules. Native and
> GPU-accelerated for Windows, macOS, and Linux.

## Long description (~150 words)

> GitBench is a fast, native desktop Git client designed for developers who work
> in many repositories at once. Instead of reopening windows or re-adding
> folders, every repo stays grouped into collapsible folders in one sidebar, so
> you can jump between projects instantly.
>
> It's a GPU-accelerated app with a readable visual commit graph for tracing
> branches and merges, inline diffs for reviewing and staging changes
> file-by-file or folder-by-folder, and full branch management — checkout,
> rename, delete, merge, rebase, and fast-forward, both local and remote.
> GitBench also handles the parts real repositories actually have: worktrees,
> stashes, and submodules.
>
> GitBench drives your existing Git command line, checks for updates on launch,
> and applies them in one click. It's completely free and open source, with
> native builds for Windows, macOS (Apple Silicon and Intel), and Linux. Source
> and every release are on GitHub.
